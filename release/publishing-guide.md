# GitHub 上傳與發布指南

## Repository 名稱

`ai-to-agent-brain-distillation-method`

## 上傳準備

1. 解壓縮 ZIP，開啟同名資料夾。
2. 閱讀 README、LICENSE 與 NOTICE。確認法律權利人及授權範圍；本包不預先授予開放授權。
3. 在 GitHub 建立同名 repository，自行選擇擁有者與可見性。本任務未指定帳號或公開範圍。
4. 上傳資料夾內的檔案與子目錄，使 README.md 位於 repo 根目錄。不要只上傳 ZIP，也不要再多包一層資料夾。
5. 若網頁上傳未包含 .github 與 .gitignore，使用 Git 用戶端補入，核對實際檔案清單。
6. 開啟 README、10 張圖片與課程連結，確認 GitHub 顯示正常。
7. 以 repo-metadata.json 的 Description 與 Topics 設定 About；未提供有效網站，因此不填 Website。

## Release

授權及遠端檢查完成後，可建立 v0.1.0 tag，將 release-notes-v0.1.0.md 內容用於 Release。標籤應對應完成檢查的 commit；不覆蓋既有 tag。
