# 證據管理工具與課堂學習卡

原有三張管理工具保留，用於檢查機制與判斷依據；課堂另以一頁蒸餾卡練習知識傳遞。兩者任務不同，不互相取代。

| 類別 | 工具 | 用途 |
|---|---|---|
| 證據管理 | 證據檢驗表 | 判斷資料對特定主張的支持程度 |
| 證據管理 | 預註冊預測卡 | 看新結果前記下預期與反例條件 |
| 證據管理 | 研究判讀與證據缺口表 | 說明已知、未知與下一步 |
| 課堂學習 | 思考拆解卡 | 找出觀察與選擇理由 |
| 課堂學習 | 一頁蒸餾卡 | 寫出原則、流程、案例與邊界 |
| 課堂學習 | 重用檢查卡 | 記錄他人理解與使用的障礙 |

## 證據檢驗表

每次先限定一條主張及其適用情境，再標記：

- **Support（支持）：** 資料符合預期機制，但仍須檢查替代解釋；不代表普遍證實。
- **Partial（部分支持）：** 只支持其中一段推論，其他必要環節尚未建立。
- **Irrelevant（無關）：** 資料沒有觸及本次限定的主張。
- **Counterexample（反例）：** 在適用條件成立且資料足夠時，出現與預先界定主張相衝突的觀察。

資料不足時記「待判定／資料不足」，不要強迫放入四類，更不能把沒資料視為無關或反例。

## 預註冊預測卡

先寫 Expected Observation、Expected Irrelevance、Counterexample Trigger、Primary Attack，保存日期與版本，再看新的結果。Primary Attack 是最值得挑戰的假設或替代解釋。

已看過案例結果後填寫，只能稱為「回溯分析」，不可稱事前預測。後續可以修訂，但保留原版與理由，不把修訂後的內容倒寫成原始預測。

## 研究判讀與證據缺口表

分別寫已知事實、推論、未知、可支持到哪裡，以及下一步補證方式。完成這張表不等於完成研究。

本教材不提供新的 OOS 檢驗結果，也不要求學員在兩小時內執行研究實測。
